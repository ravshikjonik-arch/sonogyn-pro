# Анатомия шейки матки —квик-референс для врача

## Эмбриология
- Шейка матки формируется при слиянии парамезонефральных (мюллеровых)
  протоков на 12–16-й неделе внутриутробного развития.

## Размеры и форма
| Параметр | Значение |
|---|---|
| Длина влагалищной части шейки | 2–3 см |
| Толщина стенки шейки | 1–1,2 см |
| Длина цервикального канала (наружный зев → перешеек) | до 4 см |
| Ширина цервикального канала | до 4 мм |
| Толщина многослойного плоского эпителия (МПЭ) | 150–200 мкм |
| Средняя ширина зоны трансформации (ЗТ) | ~6 мм |

## Эпителий экзоцервикса (МПЭ) — 4 слоя
1. **Базальный** — источник регенерации; в патологии — источник
   аномальной пролиферации
2. **Парабазальный** — 2–3 ряда клеток
3. **Промежуточный** — 6–12 рядов, богат гликогеном
4. **Поверхностный** — 12–18 рядов, выражен в пролиферативной фазе цикла

## Эпителий эндоцервикса (ЦЭ)
- Однослойный высокий цилиндрический эпителий, секреторная функция
- Резервные клетки у границы с МПЭ → способны к плоскоклеточной
  метаплазии (основа формирования ЗТ)

## Типы зоны трансформации (ЗТ) — клиническое значение
| Тип | Локализация | Кольпоскопическая визуализация |
|---|---|---|
| ЗТ 1 | Полностью на эктоцервиксе | Видна на 100% — оптимально для диагностики |
| ЗТ 2 | У наружного зева, частично в канале | Видна только внутренняя граница — встречается чаще других |
| ЗТ 3 | В цервикальном канале | Кольпоскопически не оценивается; вариант нормы в менопаузе и после деструктивного лечения |

## Признаки атипической ЗТ (требуют внимания при КС)
- атипичные сосуды
- ацетобелый эпителий
- мозаика / пунктация
- йоднегативные зоны

→ подробный разбор кольпоскопических критериев — в главе «Диагностика»

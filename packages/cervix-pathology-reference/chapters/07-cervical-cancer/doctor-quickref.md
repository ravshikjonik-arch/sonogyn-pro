# Рак шейки матки (РШМ) — квик-референс

> См. также `self-assessment/data/quiz-bank.json` для версии стадирования
> **FIGO 2018** (более новая, с подкатегориями IB1/IB2/IB3 и IIIC1/IIIC2,
> допускающая лучевые методы). Таблицы ниже — по системе **TNM/FIGO в
> редакции учебника 2018 г.**, без подкатегорий IB1-3/IIIC — для полной
> клинической практики ориентируйся на актуальную версию FIGO 2018+.

## Эпидемиология
- 2-е место среди онкозаболеваний у женщin в мире (ВОЗ)
- РФ: прирост заболеваемости ~2,5%/год; раннее выявление — только 28%;
  III–IV стадия на момент диагностики — >30%
- ВПЧ-ассоциация: 14 онкогенных типов; 16/18 → >70% случаев

## Морфологические типы
| Тип | Частота |
|---|---|
| Плоскоклеточный (с/без ороговения) | 70-80% |
| Аденокарцинома (железистый) | 10-20% |
| Низкодифференцированный | ~10% |
| Прочие типы | <1% |

## Стадирование (TNM / FIGO, общая логика)
| Стадия | Суть |
|---|---|
| 0 (Tis) | Опухоль только на поверхности, без инвазии |
| I | Инвазия ограничена шейкой/телом матки |
| II | Распространение за пределы матки, без стенок таза/нижней части влагалища |
| III | Стенки таза, нижняя треть влагалища, нарушение проходимости мочеточников, и/или метастазы в регионарных л/у |
| IV | Мочевой пузырь/прямая кишка, выход за пределы таза, и/или отдалённые метастазы |

⚠️ Стадия фиксируется **один раз** при первичной постановке диагноза и
не меняется при прогрессии/рецидиве — добавляется только доп. информация.

## Обязательный объём обследования для стадирования
Осмотр + расширенная КС · цитология экзо-/эндоцервикса · гистология
биоптата · УЗИ малого таза/брюшной полости/забрюшинного пространства ·
КТ малого таза · (по показаниям: урография, цистоскопия, сцинтиграфия костей)

## Клиника
- Преинвазивный рак: бессимптомен в 6–16% случаев
- Кровянистые выделения — контактные/ациклические (репродуктивный
  возраст) или периодические/постоянные кровотечения (постменопауза)
- Водянистые выделения (часто с запахом)
- Боли — признак распространённого процесса (пояснica/крестец/прямая кишка)

## Метастазирование
**Лимфогенное — по этапам:**
1. Наружные/внутренние подвздошные + запирательные л/у
2. Общие подвздошные л/у
3. Поясничные л/у
4. Л/у средостения и надключичные

**Зависимость от глубины инвазии:**
| Глубина инвазии | Частота лимфогенных метастазов |
|---|---|
| <1 мм | Метастазов не бывает |
| <3 мм | 1% |
| 3-5 мм | 5-8% |
| Стадия I | 15-18% |
| Стадия II | 25-30% |
| Стадия III | 50-60% |

**Гематогенное:** лёгкие, печень, кости

## Лечение по стадии
| Стадия/ситуация | Метод |
|---|---|
| Микроинвазивный рак | Конизация / ампутация по Штурмдорфу |
| I стадия | Расширенная экстирпация матки с придатками; либо расширенная трахелэктомия |
| IA2-IB1, желание сохранить фертильность | Радикальная абдоминальная трахелэктомия (в РФ — модификация с сохранением маточных сосудов) |
| IB-IIA | Расширенная экстирпация матки с придатками (операция Вертгейма) |
| Противопоказания к операции | Внутриполостная лучевая терапия |
| IB-IIA (иногда IIB) | Комбинированное лечение (операция + ЛТ) |

## Диспансерное наблюдение после лечения
- Год 1: 4 раза · Год 2: 2 раза · далее: 1 раз/год
- Состав: клин. осмотр + расширенная КС (+биопсия по показаниям) + УЗИ
  малого таза/брюшной полости/забрюшинного пространства + Rg грудной
  клетки + (по показаниям КТ, цистография, сцинтиграфия костей)

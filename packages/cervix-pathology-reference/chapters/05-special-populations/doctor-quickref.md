# Шейка матки у подростков, беременных, в менопаузе — квик-референс

## Подростки
- КС — инвазивное исследование, только по строгим показаниям:
  рецидивирующие выделения неясной причины, кровотечения в период
  гормонального покоя, аномалии развития (атрезия девственной плевы),
  подозрение на опухоль малого таза, несоответствие возраста и
  физического развития, подозрение на инородное тело
- КС нельзя проводить в принудительном порядке → по показаниям с
  обязательным осмотром — под наркозом

## Беременность
**Физиологические изменения:** гипертрофия, цианотичность, усиленный
сосудистый рисунок, увеличение существовавшей эктопии, выворот ЦЭ

**Децидуоз** (~у 1/3 беременных) — полиповидные разрастания у наружного
зева. Отличие от полипа: **не лечится, исчезает самостоятельно после
родов**

**Частота:** эктопия — часто; истинная эрозия — 20-40%

**РШМ при беременности:**
- Основной симптом — вагинальное кровотечение (68% случаев)
- I триместр → маскируется под угрожающий выкидыш
- II-III триместр → маскируется под предлежание/отслойку плаценты

**Тактика при аномальной цитологии (по ASCCP 2003 / IARC 2008):**
| Правило | |
|---|---|
| Биопсия при тяжёлой дисплазии/инвазии | только опытным специалистом под КС-контролем |
| Выскабливание цервикального канала у беременной | **недопустимо** |
| При исключённой инвазии | КС + цитологический контроль без лечения |
| Контроль по IARC | цитология + КС 1 раз/мес при подозрении на инвазивный РШМ |
| Финальная оценка шейки после родов | не ранее 6 недель |

⚠️ Лечебная тактика РШМ во время беременности зависит от стадии и
триместра постановки диагноза — индивидуальный план, мультидисциплинарно
(онкогинеколог + акушер).

## Менопауза
- Атрофия эпителия + втягивание стыка эпителиев в канал (зона
  труднодоступна для осмотра)
- Атрофические изменения **могут имитировать ЦИН** (↑ ядерно-
  цитоплазматическое соотношение) → риск гипердиагностики
- Зеркала подбирать по размеру + лубриканты (профилактика ятрогенной
  травмы и искажения картины)
- При неясной КС/цитологии: короткий курс местного эстриола →
  повторное исследование (часто избегает ненужной инвазивной
  диагностики)

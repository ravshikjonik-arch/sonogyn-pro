# Самопроверка: патология шейки матки

Банк вопросов для модуля `self-assessment` в составе `cervix-pathology-reference/`.
Два уровня сложности (поле `level` в JSON):

- **doctor** — для практикующего врача (тактика, стадирование, нюансы ведения)
- **student** — для студента/молодого врача (термины, базовые классификации)

## Источники

Контент составлен по открытым международным и российским клиническим
рекомендациям, пересказан своими словами (без копирования формулировок
первоисточников):

1. **Клинические рекомендации «Рак шейки матки»**, Минздрав России,
   утверждены 2024 г., пересмотр не позднее 2026 г.
2. **Клинические рекомендации «Цервикальная интраэпителиальная неоплазия,
   эрозия и эктропион шейки матки»**, Минздрав России, 2024 г.
   ⚠️ **Важно:** разные правовые базы по-разному отмечают статус вступления
   в силу этого документа. Перед публикацией в проде проверь актуальный статус
   на рубрикаторе **cr.minzdrav.gov.ru**.
3. **FIGO Staging Classification for Cervical Cancer**, пересмотр 2018 г.
4. **ASCCP Risk-Based Management Consensus Guidelines**, 2019 г.
5. **IFCPC Colposcopy Nomenclature**, Рио-де-Жанейро, 2011 г.

## Структура `quiz-bank.json`

- `sources[]` — реестр источников с `id`, на которые ссылаются вопросы (`sourceId`)
- `questions[]` — вопросы с полями `id`, `category`, `level`, `question`, `options`, `correctIndex`, `explanation`, `sourceId`

Ключи — английские, значения — русские.

# Sonogyn Pro — УЗИ Базовый курс: правила для Cursor-агента

## Контекст проекта
Репозиторий: платформа sonogyn-pro (медицинская образовательная/клиническая система).
Пакет `course/` — учебный курс «УЗИ: базовый курс» для молодых врачей на основе Хофера (3-е изд., 2021).
Пакет `data/nomograms/` — номограммы фетометрии (см. ../nomograms.json).

## Структура course/
- `curriculum.json` — оглавление курса, главы, статусы (complete / outline_only)
- `modules/mNN_*.md` — конспекты-модули (Markdown, русский язык)
- `quiz/quiz.json` — вопросы для самопроверки
- `cursor-rules.md` — этот файл

## Задачи агента
1. **Рендеринг курса в UI**: сгенерируй React/Next.js-компоненты читалки модулей: оглавление (дерево из curriculum.json), страница модуля (Markdown → HTML с подсветкой таблиц), индикатор прогресса, переключатель «модуль/экзамен».
2. **Quiz-движок**: по quiz.json реализуй тестирование с вариантами ответов, пояснениями и подсчётом баллов; храни прогресс в localStorage.
3. **Связка с номограммами**: в модулях с числовыми критериями (например, аорта ≤25/≤20 мм, НПВ >20 мм) подтяни nomograms.json и покажи интерактивные карточки норм.
4. **Поиск**: добавь полнотекстовый поиск по modules/*.md (например, FlexSearch).
5. Новые модули добавляй только как Markdown по шаблону: заголовок H1, блок-цитата с источником, секции ##, таблицы для норм, блок «Вопросы для самопроверки». НЕ копируй текст книги дословно — только конспекты.

## Ограничения
- Язык интерфейса и контента — русский.
- Медицинский дисклеймер на каждой странице модуля: «Учебный материал. Не заменяет клинические рекомендации».
- Не выдумывай числовые нормы: бери только из modules/*.md и nomograms.json; если данных нет — помечай «требует оцифровки».

# УЗИ: базовый курс (sonogyn-pro)

Учебный пакет для обучения молодых врачей основам ультразвуковой диагностики.
Основан на книге: М. Хофер. «Ультразвуковая диагностика. Базовый курс», 3-е изд., М.: Медицинская литература, 2021 (ISBN 978-5-91803-010-3).

## Состав
- `curriculum.json` — программа курса: 9 глав + введение + приложение (по оглавлению книги), со статусами наполнения
- `modules/` — 17 учебных модулей:
  - **m00–m03** — Введение: физика УЗИ, новые методики (THI, CEUS, SonoCT, chirp), артефакты, практические приёмы — ✅ полностью оцифрованы (с. 7–22)
  - **m10–m13** — Глава 1: забрюшинное пространство, аорта, НПВ, правожелудочковая недостаточность — ✅ полностью оцифрованы (с. 23–30)
  - **m20–m99** — каркасы глав 2–9 и приложения по оглавлению — ⏳ требуют оцифровки страниц
- `quiz/quiz.json` — 10 тестовых вопросов с пояснениями по оцифрованным модулям
- `cursor-rules.md` — инструкции для Cursor-агента (генерация UI-курса, quiz-движок, связка с номограммами)

## Важно
Конспекты — пересказ ключевых положений книги (авторское право: дословное копирование недопустимо).
Медицинский дисклеймер: учебный материал, не заменяет клинические рекомендации.

## Курс 2: TI-RADS (узлы щитовидной железы)
- `curriculum-tirads.json` — 9 разделов + приложения по книге Катрич/Фисенко/Ветшева (СТРОМ, 2023)
- Модули `t00`–`t04` — оцифрованы (с. 7–33): эпидемиология, анатомия, технология УЗИ, полная терминология B-режима, ЦДК/ЭДК, компрессионная эластография (шкалы Rago/Asteria, SR) и эластография сдвиговой волны (SWE, ARFI, VTI/VTQ)
- Модули `t05`–`t10` — каркас (критерии, классификация TI-RADS, ТАПБ, лимфоузлы, заключение, приложения)
- `quiz/quiz-tirads.json` — 8 тестов с пояснениями

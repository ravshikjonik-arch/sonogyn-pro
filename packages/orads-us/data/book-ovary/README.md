# sonogyn-pro-orads-data — O-RADS и дифференциальная диагностика новообразований яичников

Оцифровка методического пособия «Ультразвуковая дифференциальная диагностика
новообразований яичников» (4 PDF, 32 страницы сканов) в машиночитаемый JSON.
Назначение: справочник гистологических типов + сверка правил со встроенным
движком `evaluateOradsUs2022` (калькулятор уже в `@repo/orads-us` — JSON **не**
заменяет стратификацию).

**В репозитории:** API — `@repo/orads-us/book-ovary`; фотокарточки —
`apps/web/public/clinical/orads-book/photocards` + `photocards.manifest.json`.
Исходный `CURSOR_PROMPT.md` остаётся в пакете Kimi (`orads-cursor` /
`sonogyn-pro-orads-data`).

## Файлы

| Файл | Содержимое | Источник в книге |
|---|---|---|
| `orads_lexicon.json` | Лексикон O-RADS: 35 терминов в 11 группах + балльная шкала васкуляризации (БШВ 1–4) | Таблица 1 |
| `orads_categories.json` | Категории O-RADS 0–5: критерии, риски, тактика (пре-/постменопауза); 6 типичных доброкачественных образований; параметры IOTA ADNEX; 9 правил O-RADS 2022 | Таблицы 2–3, рис. 1–2, 10–14 |
| `orads_tumor_cards.json` | 32 карточки гистологических типов: возраст, латеральность, УЗ-вид, признаки, онкомаркеры, шкала ЦДК | Раздел 2 (ESGO/ISUOG/IOTA/ESGE 2021) |

## Категории O-RADS (кратко)

| Категория | Риск малигнизации | Тактика |
|---|---|---|
| 0 | — | Повторить УЗИ или МРТ |
| 1 | 0% (нормальный яичник) | Наблюдение не требуется |
| 2 | <1% | По типу образования (см. правила) |
| 3 | 1–<10% | Контроль УЗИ через 6 мес, ведение гинекологом |
| 4 | 10–<50% | Экспертное УЗИ / МРТ, консультация гинеколога-онколога |
| 5 | ≥50% | Ведение гинекологом-онкологом |

Связь с IOTA ADNEX: риск ADNEX <1% ≈ O-RADS 2; 1–10% ≈ O-RADS 3; 10–50% ≈ O-RADS 4; ≥50% ≈ O-RADS 5.
Формула ADNEX в пособии не приведена (только параметры) — реализовывать по оригинальной публикации IOTA.

## Фотокарточки

Папка `photocards/` — 47 изображений, автоматически вырезанных со сканов:
эхограммы, схемы, таблицы и карточки опухолей. Именование: `bookN_pNN_cardM.jpg`
(N — номер исходного PDF, NN — страница, M — порядковый номер карточки на
странице). Пригодны как иллюстрации к справочнику и примеры для интерфейса
калькулятора. Обрезка выполнена автоматически и выборочно проверена вручную;
при обнаружении неточного кадрирования отдельных карточек — сообщить для
точечной переделки.

## Оговорка о точности

Данные оцифрованы со сканов — возможны единичные ошибки чтения цифр (проценты,
медианы возраста). Постраничные сканы для сверки: `../ovary/p1`–`../ovary/p4`
(p1 = стр. 26–39 книги: категории 3–5 и тактика; p2 = стр. 40–45: доброкачественные
и пограничные опухоли; p3 = стр. 50–67: злокачественные и вторичные; p4 = стр. 4–25:
лексикон и таблицы 1–3). Перед клиническим использованием рекомендуется выборочная
сверка с печатным изданием.

# Лицензии и источники (SonoGyn Pro)

Живой реестр. При добавлении OSS / 3D-моделей / крупных цитат — дописать строку.

## Платформа (код)

| Компонент | Лицензия / заметка |
|-----------|-------------------|
| Monorepo SonoGyn Pro | Проприетарный продукт (закрытый код приложения) |
| Next.js, React, Expo и пр. | По `package.json` / SPDX зависимостей; `pnpm licenses` при аудите |
| `@repo/clinical-3d` | Код пакета — продукт; процедурные модели (breast/ovary/…) — наши |
| Матка 3D (legacy) | `@clinical/uterus` / `apps/web` uterus-3d — внутренний модуль |

## Клинические классификации (логика, не «скан книги»)

| Система | Опора | В продукте |
|---------|--------|------------|
| O-RADS US | ACR | `packages` / калькуляторы web |
| BI-RADS US | ACR | то же |
| TI-RADS | ACR | то же |
| IOTA | IOTA group publications | то же |
| FIGO | Munro / FIGO | clinical-3d uterus / калькуляторы |

Формулировки в UI — справочные; не копировать целые главы учебников.

## Планируемый модуль малого таза (PELVIS_3D)

| Элемент | Статус | Требование |
|---------|--------|------------|
| Интерактивная модель таза | Каркас UI за флагом | Перед вкл. по умолчанию — OSS-модель с **совместимой** лицензией (CC-BY / MIT и т.п.), источник и SPDX сюда |
| JSON структур / DIE checklist | В репо | Не заменяет анатомический атлас из книги |

Пока флаг выключен — модуль не обещает чужую 3D-геометрию.

## Запрещено без юр. проверки

- PDF / сканы страниц из учебников и атласов
- Клинические фото пациентов без согласия и de-ID
- AGPL/GPL зависимости в закрытом продукте без отдельного решения

## Как проверять

```bash
# обзор зависимостей (при необходимости)
pnpm licenses list
```

Обновлять этот файл при каждом новом крупном OSS или 3D-ассете.

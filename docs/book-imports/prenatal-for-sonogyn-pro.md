# Что забираем в SonoGyn Pro из «Пренатальной эхографии»

Источник: русскоязычное руководство по пренатальной эхографии, 20 глав, 552 стр.
Материалы: `extracted/` (текст всех глав), `images/` (1101 иллюстрация с подписями и классификацией), `sonogyn-us-atlas/` (725 УЗИ-снимков).

## 1. Прямое пополнение obstetric-dx / StructuredReportPreview

| Глава | Что взять | Куда |
|---|---|---|
| 1 — Эхография в акушерстве | Принципы скринингов, чувствительность по ВПР, структура пропущенных ВПР | База знаний скринингов, обоснование чек-листов протоколов |
| 2 — УЗ-фетометрия | Таблицы норм БПР, ЛЗ, ОГ, ОЖП, ДБК, плюс методика измерений (оси, стандартные срезы) | Модуль фетометрии: русская терминология + контроль качества срезов |
| 3 — Плацента, пуповина, воды | Градации зрелости плаценты, локализация/предлежание, обвитие, индекс амниотической жидкости | StructuredReportPreview: разделы плацента/воды; словарь RU-терминов |
| 4 — Многоплодная беременность | Хорионность, дискордантность, TTTS, оценка роста каждого плода | obstetric-dx: ветка «многоплодие» в протоколе |
| 5 — 3D-эхография | Режимы поверхностной/объемной реконструкции, применимость | Справочник режимов для раздела «оборудование/методика» |
| 8 — Воротниковое пространство | Протокол измерения ТВП, нормы по неделям | Фетометрия I триместра (уже есть задел — дополнить RU-терминами) |
| 9 — Длина костей носа | Методика + нормы, связь с трисомиями | I-триместровый скрининг |

## 2. Нормы допплера → JSON-калькулятор (кандидат на новый модуль)

Главы **6** (маточно-плацентарный кровотоко во II–III триместрах) и **11** (те же сосуды в ранние сроки) дают полный набор: маточные артерии (ИР/ПИ, нормализация к 24 нед), артерии пуповины (КСК = комплекс спектрального кривого анализа: С/Д, ИР, ПИ), средняя мозговая артерия (Церебрально-плацентарное отношение), венозный проток (реверс в фазу предсердий). Плюс требования безопасности: TI/MI ≤ 1,0 (FDA).

Это готовая структура для **калькулятора допплера по неделям** — по аналогии с уже сделанным O-RADS wizard'ом: выбор сосуда → ввод ИР/ПИ/СД → вердикт «норма / подозрение / патология» с цитатой норматива. Условные обозначения книги (КСК, ЦДК, ПДК, ЭДК) уже расшифрованы в наших извлечениях — RU-интерфейс бесплатно.

| 20 | Опорно-двигательная | 52 |

Каждая глава структурирована по одной схеме: эмбриология → норма на УЗИ → классификация порока → УЗ-признаки (с номерными рисунками-ссылками на наш атлас) → дифференциальная диагностика → прогноз. Это прямо ложится в формат карточки порока для справочника SonoGyn Pro: название (RU), УЗ-признаки, отличия от похожих находок, иллюстрация из `sonogyn-us-atlas/`.

## 4. Что не берём

- Плакатные/статистические диаграммы первой главы (графики, не УЗИ).
- Литературные обзоры и исторические разделы — полезны только как ссылки.
- Схемы (118 шт.) — можно подключить позже к разделу «обучение», если понадобятся иллюстрации методики измерений.

## Оговорки

- Подписи к рисункам извлекались автоматически (ближайший текстовый блок); у ~5% кадров подпись обрезана или взята с соседнего рисунка — сверять по `pdf_page` в `index.csv`.
- 258 иллюстраций остались типом `other` (нет УЗИ-маркера в подписи), но визуально большинство из них — УЗИ-кадры. При необходимости расширить атлас — ручная или полуавтоматическая переклассификация.
- Книга 2000-х годов: часть нормативов (особенно по скринингу) устарела относительно современных руководств (ISUOG, FMF) — использовать как второй источник, сверяя с актуальными протоколами.

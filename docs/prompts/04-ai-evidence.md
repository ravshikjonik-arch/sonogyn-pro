# Этап 4. Исслед. AI + Evidence (углубить помощника)

```
Ветка: feature/ai-evidence.

Контекст продукта: «Исслед. AI» = /ai/consultants (помощник врача), не витрина OSS.
Evidence: /tools/refs/evidence*, adapters уже могут существовать — не плоди вторую шину.

Цель: ответы с опорой на источники + ссылки + дисклеймер.

Приоритет источников: PubMed, ClinicalTrials.gov, КР Минздрава/рубрикатор, ГРЛС, OpenAlex (если уже есть).
Платные (Scopus, WoS, eLIBRARY) — заглушки-адаптеры.

Архитектура (packages-first / рядом со старым):
1. Единый SourceAdapter { search, fetch }; новый источник = новый файл.
2. Кэш + rate limit к внешним API.
3. Ответ: краткий вывод + источники; если пусто — честно сказать.
4. Пометка «справочно, решение принимает врач» в каждом клиническом ответе.
5. Логи без PHI; мок-тесты адаптеров.
6. Навигация/поиск: «Исслед. AI» и хаб консультантов остаются единой точкой входа.

Флаг AI_EVIDENCE_V2 при рисках регрессии. Не возвращать /tools/repos как дамп README.
```

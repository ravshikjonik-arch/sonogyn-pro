3. Картинки из книг → свои схемы/иконки или короткая цитата + источник.
4. Удаление из рабочей версии — после «ок»; git history отдельно (чек-лист, без filter-branch без запроса).
5. Регрессия: маршруты калькуляторов, атласы, education — не 404 и не пустые экраны.

Итог: удалено / добавлено / smoke. Юрист — до публичного маркетинга цитат.

# Этап 5. 3D малого таза (новый модуль рядом, за флагом)

```
Ветка: feature/pelvis-3d. Изолированный модуль: не ломает калькуляторы и помощника.

Цель: интерактивная 3D-модель женского малого таза для оценки глубины инфильтрации
при тазовом инфильтративном эндометриозе (справочно, не диагноз).

Структуры: матка, шейка, яичники, мочевой пузырь, сосуды, круглые / воронкотазовые /
крестцово-маточные связки, лимфоузлы.

1. three.js / R3F; открытая модель с лицензией → docs/LICENSES.md (или раздел в существующем licenses).
2. Вращение, zoom, raycast; по клику — название + JSON вовлечённых структур.
3. Режим «глубина инфильтрации»: подсветка слоёв + УЗИ-чеклист (формулировки справочные).
4. Lazy load; не раздувать первый экран кабинета.
5. Touch / слабые устройства.

Флаг PELVIS_3D. Точка входа: отдельный route под tools/mapping или assistant — согласовать в STEP 3–4.
Анатомия — сверка с экспертом до «вкл. по умолчанию».
```

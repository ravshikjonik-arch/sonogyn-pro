# SonoGyn Pro — Clinical Standards RU

Стартовая структура нормативной и клинической библиотеки для амбулаторного акушера-гинеколога РФ.

**Статус:** каркас и реестр официальных источников. Это не завершённая юридическая экспертиза всех документов и не утверждённый локальный клинический протокол.

## Как пользоваться
1. Откройте `00_Реестр_источников_и_документов.md`.
2. Для каждого документа проверьте статус и редакцию на дату применения.
3. Скачивайте оригинал только с официального источника или сохраняйте точную ссылку на официальный первоисточник.
4. Заполняйте карточку документа по шаблону `Карточка_нормативного_документа.md`.
5. Региональный раздел нельзя считать готовым до выбора субъекта РФ.

## Принципиальные правила
- Не смешивать нормативные правовые акты, клинические рекомендации, стандарты и методические рекомендации.
- Не превращать рекомендацию «по показаниям» в обязательное обследование для всех.
- У каждой клинической подсказки должна быть связь с конкретным источником, разделом, редакцией и датой проверки.
- Устаревшие документы перемещать в архив, не удалять историю.
- В медицинских алгоритмах фиксировать показание, возрастные ограничения, периодичность, противопоказания и маршрут пациента.

# Матрица алгоритмов амбулаторного приёма

| Маршрут | Что должен определять алгоритм | Связанные документы |
|---|---|---|
| Первичный профилактический приём | Возраст, цель осмотра, факторы риска, скрининг | Порядок профилактики, КР по выявленным состояниям |
| ДОРЗ | Критерии включения, этап, возраст, периодичность, исследования | Действующие документы ДОРЗ и методические рекомендации |
| Нарушение менструального цикла | Анамнез, исключение беременности, причины, показания к гормональным тестам и УЗИ | КР по аменорее/олигоменорее, СПКЯ, АМК |
| АМК | Оценка тяжести, исключение беременности, PALM-COEIN где применимо, обследование эндометрия | КР по АМК, гиперплазии и полипам эндометрия |
| Тазовая боль | Исключение неотложных состояний, инфекционные и неинфекционные причины | КР по ВЗОМТ, эндометриоз, внематочная беременность |
| Выделения / вагинит | Клиническая оценка, дифференциальная диагностика, целевые тесты | КР по вагинитам и ИППП |
| Патология шейки матки | Скрининг, цитология, ВПЧ, кольпоскопия и биопсия по алгоритму | КР по CIN и онкологические документы |
| Бесплодие | Обследование пары, овуляция, трубы, маточный фактор, мужской фактор | КР по женскому бесплодию |
| Образование яичника | УЗ-морфология, риск, динамика и маршрутизация | КР по доброкачественным образованиям яичников; O-RADS/IOTA как классификационные инструменты в пределах показаний |
| Миома / аденомиоз | Симптомы, анемия, морфология, репродуктивные планы | КР по миоме и соответствующие рекомендации |
| Менопауза | Симптомы, противопоказания и риски терапии | КР по менопаузе |
| Молочная железа | Клиническая оценка, возраст и показания к визуализации, подозрительные признаки | КР по доброкачественным заболеваниям и онкологическая маршрутизация |

Матрица является планом разработки. Конкретные назначения должны быть извлечены из актуальной КР и нормативного документа, проверены по пунктам и адаптированы к пациентке.

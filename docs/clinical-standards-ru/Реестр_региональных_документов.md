# Реестр региональных документов

**Регион пока не задан.** Не заполнять этот раздел документами другого субъекта РФ.

После указания региона внести:
- субъект РФ;
- региональное министерство / департамент здравоохранения;
- официальный портал правовой информации субъекта;
- территориальную программу госгарантий;
- тарифное соглашение ОМС;
- региональный порядок маршрутизации;
- приказы по женским консультациям и межрайонным центрам;
- маршруты по онкологической настороженности;
- региональные регламенты лабораторной и инструментальной диагностики;
- локальные документы конкретной медицинской организации.

Для каждого документа создать отдельную карточку по шаблону.

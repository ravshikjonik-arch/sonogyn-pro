# Направление O-RADS калькулятора

Цель: сделать быстрый O-RADS US сценарий как управляемый клинический помощник, но с преимуществами
SonoGyn Pro: расчет по тексту, AI-помощник, визуальные примеры и ссылки на доказательную базу.

## Режимы

1. Пошаговый мастер
   - один клинический вопрос за шаг
   - логика ACR/O-RADS остается детерминированной
   - крупные кнопки для приема и мобильного экрана

2. Расчет по тексту
   - врач вставляет описание УЗИ
   - парсер извлекает менопаузу, размер, структуру, подтип, солидный компонент, кровоток, асцит
   - система считает предварительную категорию O-RADS
   - сомнительные поля показываются как “проверьте вручную”

3. AI-помощник
   - объясняет, какие недостающие признаки могут изменить категорию
   - подсказывает, что проверить на снимке
   - не выдает себя за автономную диагностику
   - будущий этап: помощь по изображению для папиллярных разрастаний, солидного компонента, кровотока, асцита

## Правило безопасности

AI-слой помогает заполнить или уточнить структурированные признаки. Итоговую категорию O-RADS считает
детерминированный калькулятор.

## Правило UX

Врач должен попасть к ответу за 1-2 клика:

- Инструменты -> O-RADS -> Пошаговый
- Инструменты -> O-RADS -> По тексту
- AI-помощник -> “помоги классифицировать образование придатков” -> O-RADS с предзаполненными признаками

## Один вход без дублей

Канонический маршрут:

- `/tools/calc/rads/o-rads`

Старые маршруты остаются только как мосты/редиректы:

- `/calculators/o-rads` -> `/tools/calc/rads/o-rads`
- `/orads-calculator` -> `/tools/calc/rads/o-rads`
- `/tools/o-rads` -> `/tools/calc/rads/o-rads`
- `/library/orads-guide` -> `/tools/refs/orads-guide`
- `/library/orads-echograms` -> `/tools/refs/orads-echograms`
- `/library/ozerskaya-iota-orads` -> `/tools/refs/orads-echograms`

Пользовательские ссылки, поиск, боковая навигация и каталог инструментов должны вести в канонический маршрут.
Справочник и эхограммы остаются отдельными страницами, но как вкладки/кнопки внутри O-RADS сценария, а не как
конкурирующие входы.

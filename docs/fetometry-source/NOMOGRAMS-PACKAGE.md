# Номограммы для Sonogyn Pro

Набор данных и инструкция по внедрению номограмм фетометрии плода (I, II–III триместры, нейросонография, допплерометрия, эхокардиография плода) в платформу **sonogyn-pro**.

## Состав пакета

| Файл | Назначение |
|---|---|
| `nomograms.json` | 45 номограмм, 832 строки данных + балльная система риска трисомий + клинические определения |
| `nomograms.schema.json` | JSON Schema для валидации датасета (CI-тесты) |
| `nomogram.service.ts` | Пример сервиса: оценка замера относительно номограммы с интерполяцией |

## Структура номограммы

```json
{
  "id": "bpd_16_40",
  "key": "BPD",
  "title": "Бипариетальный размер (БПР)",
  "source": "Медведев и соавт., 1999",
  "category": "second_third_trimester",
  "unit": "mm",
  "x_axis": { "type": "ga_weeks", "label": "Срок беременности (нед)" },
  "percentiles": [5, 50, 95],
  "rows": [ { "ga_weeks": 16, "p5": 31, "p50": 34, "p95": 37 } ]
}
```

### Типы оси X (`x_axis.type`)

- `ga_weeks` — срок в неделях (целое), поля строк `ga_weeks`
- `ga_days` — срок «нед+дни», поле `ga` в формате `"12+4"` (КТР, венозный проток)
- `crl_range_mm` — диапазон КТР в мм, поля `crl_min`/`crl_max` (ТВП, ДНК, IV желудочек)

### Особые строки (не перцентили)

- `dv_pi` (венозный проток): `min`, `mean_low`, `mean_high`, `max`
- `mca_psv_16_39` (ПССК в СМА): `median`, `mom_1_5` (порог 1,5 MoM для анемии)
- ЭхоКГ с перцентилями 2,5/50/97,5 хранят значения в полях `p5/p50/p95` (см. `percentiles`)

### Категории

`first_trimester`, `second_third_trimester`, `doppler`, `fluid`, `neurosonography`, `fetal_echo`

## Внедрение через Cursor

1. Положите `nomograms.json` в проект, например `src/data/nomograms.json`.
2. Добавьте валидацию: `nomograms.schema.json` → тест на `ajv`/zod в CI.
3. Промпт для Cursor (Composer/Agent):

> Импортируй src/data/nomograms.json в модуль данных. По nomograms.schema.json сгенерируй TypeScript-типы. Реализуй сервис оценки замера: на вход ключ показателя, срок беременности и значение; на выход — положение относительно перцентилей (BELOW_P5 / P5_P50 / P50_P95 / ABOVE_P95), интерполированные границы и статус. Для x_axis.type = "ga_days" парси формат "нед+дни" в дни; для "crl_range_mm" ищи строку по величине КТР. Покрой unit-тестами краевые случаи (срок вне диапазона, между неделями).

4. Промпт для UI-виджета:

> Сделай React-компонент NomogramChart: график перцентильных кривых (p5/p50/p95) по неделям, точка текущего замера пациентки, подсветка зоны вне референса. Данные из nomograms.json, категория second_third_trimester.

5. Балльную систему трисомий (`scoring_systems`) подключите к модулю скрининга: сумма баллов ≥ 2 → рекомендация кариотипирования.

## Проверка качества данных

Данные перенесены вручную из сканированного PDF. Перед продакшеном рекомендуется:
- сверить 10–15 случайных строк с оригиналом;
- обратить внимание на строку КТР `12+4` (в скане p95 нечитаемо, восстановлено по ряду: 69);
- строку ИАЖ 27 нед. (принято 146 мм, в скане возможен дефект печати).

## Лицензионное примечание

Номограммы основаны на публикациях Алтынника, Медведева, Козлововой и др. Используйте в соответствии с лицензией вашей клинической системы; указывайте источник (`source` поле) при отображении в UI.

# Стандарт клинической валидации калькуляторов

**Статус:** проект на утверждение. Существующие golden-наборы: `docs/clinical-imaging-cds/golden-set/` (+ `ANNOTATION-GUIDE.md`) — используются как основа.

## 1. Обязательные категории тестов для каждого калькулятора

| Категория | Что проверяет | Пример (O-RADS) |
|---|---|---|
| Положительные | каждая строка официальной таблицы даёт свой результат | multilocular гладкая 6 см CS 2 → 3 |
| Отрицательные | признак, который не должен менять результат, не меняет | асцит при O-RADS 2 → 2 + предупреждение |
| Пограничные | значения на порогах и ±0.1 | 2.9 / 3.0 / 3.1; 9.9 / 10 см |
| Отсутствующие | нет обязательного признака → `incomplete` + список | нет color score у multilocular |
| Не оценено | `not_assessed` не равно «нет» | асцит не оценён → нет финальной категории 3/4 |
| Противоречивые | несовместимые признаки → `invalid` | папиллы при «солидного компонента нет» |
| Некорректные | неверный тип / единицы / диапазон → `invalid` | размер «abc», 0 мм, 5000 мм |
| Неприменимость | сценарии вне алгоритма → `not_applicable` | перекрут нормального яичника |
| Детерминизм | 2 одинаковых вызова → одинаковый результат | — |
| Паритет | все реализации/платформы дают одно и то же | дерево ↔ сетка; web ↔ mobile |
| Соответствие таблицам | машинно-читаемая таблица строк официального документа (собственная формулировка) → тест на каждую строку | Assessment Categories v2022 |
| Регрессия | зафиксированные исторические баги | bilocular при 3 перегородках |

## 2. Правила

1. Тест-скрипты пакетов — с **кавычками в glob** (`"src/**/*.test.ts"`), иначе часть тестов не запускается (найдено в `medical-calculations`).
2. Каждый пакет движка входит в CI (`.github/workflows/ci.yml`).
3. Изменение клинического правила требует: ссылку на первоисточник, обновление таблицы соответствия, подпись врача-эксперта в PR.
4. Golden-набор — синтетические случаи, без ПДн.
5. Метрика покрытия: каждая строка официальной таблицы ≥ 1 тест; каждое поле входа ≥ 1 тест на отсутствие.

## 3. Клиническая приёмка

- Чек-лист врача-эксперта в PR (как в [O-RADS_ACR_V2022_AUDIT.md §4](./O-RADS_ACR_V2022_AUDIT.md)).
- Статус в реестре меняется на `expert_reviewed` / `approved` только после чек-листа.

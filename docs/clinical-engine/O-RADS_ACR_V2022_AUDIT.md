## 1. Матрица ACR REQUIREMENT → CURRENT → GAP → REQUIRED TEST

### Governing Concepts (GC 1–9)

| # | Требование ACR v2022 | Текущая реализация | Разрыв | Нужный тест |
|---|---|---|---|---|

| Требование | Текущая реализация | Разрыв | Нужный тест |
|---|---|---|---|
| Нормальный яичник / фолликул ≤3 см / жёлтое тело → O-RADS 1 | ✓ (дерево, сетка, Pro) | — | — |
| Простая киста: пре ≤3 → 1 (фолликул); пре >3–<10 → 2; пост ≤3/ >3–<10 → 2; ≥10 → 3 | сетка ✓ | сверить управление (12 мес.) | таблица границ 3 / 5 / 10 см × пре/пост |
| Однокамерная гладкая непростая: ≤3 см пре — без наблюдения, пост — 12 мес.; >3–<10 — 6 мес. | сетка ✓ | — | границы 3 / 10 см |
| **Bilocular** (v2022): **2 камеры = 1 полная перегородка**, гладкая, <10 см → 2; ≥10 см → 3 независимо от CS | сетка ✓ (морфология `bilocular`); **Pro-адаптер: bilocular при `septaCount = "1-3"`** | **Gap P0:** 2–3 перегородки (3–4 камеры) классифицируются как bilocular (O-RADS 2) вместо multilocular (O-RADS 3/4 по CS и размеру) | «3 перегородки, гладкая, 6 см, CS 2» → O-RADS 3 (не 2) |

| Двух-/многокамерная с солидом: CS 1–2 → 4; CS 3–4 → 5 | сетка ✓ | — | — |
| Солидное: неровный контур → 5; гладкий: CS 1 → 3; CS 2–3 → 4; **с тенью и CS <4 → 3**; CS 4 → 5 | сетка ✓ | — | тень × CS 1–4 |
| Classic benign: геморрагическая (1 камера), дермоид и эндометриома (≤3 камер), **без внутреннего кровотока**; ≥4 камер → пересчёт как multilocular | выбор подтипа; камеры и кровоток **не проверяются** | **Gap P1:** подтип без проверки дескрипторов | эндометриома с 4 камерами → multilocular |

| Внеовариальные classic (параовариальная, перитонеальная инклюзионная, гидросальпинкс) → 2 любого размера | Pro: **все внеовариальные → classic** | **Gap P1:** атипичное внеовариальное образование получает O-RADS 2 | атипичное внеовариальное → оценка по лексикону |

**Последствия для SonoGyn Pro (не юридическая консультация — нужен юрист):**

3. Название системы использовать как ссылку на стандарт с пометкой «O-RADS™ — товарный знак American College of Radiology; SonoGyn Pro не аффилирован с ACR», без логотипов ACR.
4. **Направить запрос в ACR** о лицензировании O-RADS (и BI-RADS / TI-RADS) для коммерческого ПО — до публичного маркетинга функций.

## 4. Чек-лист клинической проверки (врач-эксперт)

- [ ] Bilocular vs multilocular: 1 / 2 / 3 перегородки, гладкие, 6 см, CS 2
- [ ] Простая киста: пре/пост × 2.9 / 3.1 / 4.9 / 5.1 / 9.9 / 10 см
- [ ] Солидное гладкое: тень × CS 1–4
- [ ] Classic benign: эндометриома 3 vs 4 камеры; дермоид с кровотоком
- [ ] Геморрагическая: 52 г (ранняя) / 56 л (поздняя) / «58 лет, менопауза 2 года»
- [ ] Асцит при O-RADS 2 / 3 / 4
- [ ] Два образования (2 и 4) → общий результат
- [ ] Не применимо: ВЗОМТ, внематочная, перекрут нормального яичника

# SonoGyn Pro — Амбулаторный приём акушера-гинеколога

Папка содержит рабочую основу для врача амбулаторного звена:
1. `01_Чек-лист_первичного_приёма.md` — структурированный чек-лист.
2. `02_Master_Prompt_ИИ-помощника.md` — мастер-промпт для ИИ-помощника.
3. `03_Нормативная_база_и_правила_проверки.md` — реестр источников и правила актуализации.
4. `04_Оговорки_и_контроль_качества.md` — важные ограничения применения.

## Важно
Это рабочий проект документации, а не утверждённый локальный нормативный акт медицинской организации.
Перед клиническим применением необходимо проверить действующие редакции федеральных документов, клинических рекомендаций и региональных приказов на дату использования, а также согласовать шаблон с руководителем медицинской организации и ответственным за качество медицинской помощи.

Не отмечайте пункты выполненными автоматически. Назначения и диагнозы должны подтверждаться клиническими данными и решением врача.

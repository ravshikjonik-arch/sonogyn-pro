# Пакет для внедрения гайда в SonoGyn-Pro через Cursor

В пакете собрано всё содержимое PDF «Как создать идеальный протокол УЗИ в гинекологии» и задание для реализации рабочего модуля.

## Состав

- `01_GUIDE_EXTRACTED.md` — полный проверенный текст всех 17 страниц: 10 шагов, формулировки, значения, сведения об авторе и дополнительные страницы.
- `02_PROTOCOL_CONTENT.json` — машиночитаемая структура для frontend/backend: поля, варианты, единицы, повторяемые группы, формулы и шаблоны.
- `03_CURSOR_MASTER_PROMPT.md` — автономное задание Cursor на интеграцию, тестирование, push и штатный деплой.
- `source-pages/page-001.png` … `page-017.png` — изображения страниц исходного PDF для визуальной сверки.

## Внедрение в SonoGyn Pro (репозиторий)

| Что | Где |
|-----|-----|
| Исходники Kimi | `apps/web/docs/sonogyn-pro-cursor/` (этот каталог) |
| JSON / логика | `packages/gynecology-ultrasound-10-steps/` |
| UI | `/tools/calc/gyn/ultrasound-10-steps` |
| Статика PDF-страниц | `/docs/sonogyn-pro-cursor/source-pages/page-NNN.png` |

## Как запустить в Cursor

1. Папка уже в репозитории: `apps/web/docs/sonogyn-pro-cursor/`.
2. Откройте репозиторий в Cursor.
3. Откройте `03_CURSOR_MASTER_PROMPT.md`, скопируйте текст после заголовка и отправьте его агенту Cursor.
4. Убедитесь, что агент прочитал `01_GUIDE_EXTRACTED.md` и `02_PROTOCOL_CONTENT.json`.
5. Для push и production-деплоя используйте существующие защищённые доступы и CI/CD проекта. Не помещайте секреты в эти файлы или в чат.

## Важно

- PDF не содержит правил O-RADS, переменных IOTA ADNEX MODEL и подробной методички по яичникам. Cursor не должен выдумывать их.
- Числовые значения и формулировки перенесены из предоставленного документа. Это не независимая клиническая валидация.
- Биография, реклама курсов, фотографии и чужой бренд не входят в медицинский модуль, но сохранены в полной транскрипции и страницах источника.

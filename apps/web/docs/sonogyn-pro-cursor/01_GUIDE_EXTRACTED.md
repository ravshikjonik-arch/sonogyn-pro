# Шаг 1. Общие характеристики оценки матки

*Источник: страница 3.*

### Расположение

- `ANTEFLEXIO`
- `RETROFLEXIO`
- `INTERPOSITIO`

### Размеры

- Длина × толщина × ширина матки.
- Объём матки: `Д × Т × Ш × 0,52`.

### Форма

- Правильная, грушевидная.
- Шаровидная.
- Седловидная.
- Двурогая.
- Однорогая.
- Полное удвоение матки.

### Контур

- Правильный.
- Дольчатый за счёт миоматозных узлов.
- Неровный, деформирован за счёт рубцов после оперативного лечения.

### Подвижность

- Сохранена.
- Снижена.
- Ограничена (значимо ограничена).
- Тело матки не визуализируется.

# Шаг 2. Миометрий

*Источник: страницы 4–5.*

### Норма

- Однородной эхоструктуры.

### Аденомиоз — прямые признаки

#### Островки

«Определяются гиперэхогенные включения неправильной формы размерами … мм в толще миометрия».

#### Линии

«Определяются гиперэхогенные линии, расположенные в субэндометриальном слое, перпендикулярно эндометрию».

#### Кисты

«Определяются анэхогенные включения неправильной формы размерами … мм, расположенные в миометрии … стенки (соединяющиеся с полостью матки)».

### Аденомиоз — косвенные признаки

#### Тени

«Определяются веерообразные тени от миометрия … стенки матки».

#### Асимметрия стенок

«Определяется асимметрия стенок матки (толщина передней / задней стенки = … / … мм; diff … %)».

#### Шаровидная форма

Отдельный отмечаемый признак.

#### Узлы

«Определяется гипоэхогенное образование без чётких границ размерами … × … мм, васкуляризация образования хаотичная».

#### Хаотичный кровоток

Отдельный отмечаемый признак.

### Миома матки

**Каждый узел описывается отдельно.**

#### Описание

«Определяется округлое гипоэхогенное (гиперэхогенное) образование неоднородной эхоструктуры с концентрическим строением и чёткими границами размерами … × … × … мм (для крупных рассчитываем объём … × 0,52)».

#### Расположение

- По передней / задней / боковой стенке / в дне матки.
- В нижних / верхних / средних отделах.
- Интрамурально / субсерозно / субмукозно.

#### Тип

- Соответствует типу 0–7 (`FIGO, 2018`).

#### Нарушение питания

«В центре узла определяется анэхогенное образование (несколько) неправильной формы размерами … × … мм».

# Шаг 5. Эндометрий

*Источник: страницы 7–8.*

### Эхогенность

- Гипоэхогенный.
- Гиперэхогенный.
- Трёхслойный.

### Эхоструктура

- Однородной эхоструктуры.
- Неоднородной эхоструктуры.

### Срединная линия

- Визуализируется.
- Не определяется.
- Волнообразная.

### Граница с миометрием

- Чётко визуализируется.
- Визуализируется нечётко.
- Прослеживается не на всём протяжении.

### Васкуляризация

- 1–4 балла (в источнике указаны характеристики: отсутствует, умеренная, выраженная).
- Диффузная / локальная.
- С сосудами без ветвления / с разветвлением сосудов на конце.

### Гиперплазия эндометрия — осмотр на 5–7 ДМЦ

Варианты описания из источника:

1. «Гиперэхогенной эхоструктуры, утолщен, без срединной линии, со множеством анэхогенных включений, умеренной васкуляризацией (2–3 балла)».
2. «Гиперэхогенной эхоструктуры, утолщен более 14 мм (в 1 фазу цикла)».
3. «Гипоэхогенный, тонкий, с мелкими анэхогенными включениями без срединной линии, со скудной васкуляризацией».

### Локальная гиперплазия эндометрия

«В верхних (нижних) отделах определяется участок утолщения эндометрия до … мм повышенной эхогенности, неоднородной эхоструктуры, с анэхогенными включениями размером … × … мм».

### Полип эндометрия — осмотр на 3–5 ДМЦ

«В средней трети (верхней, нижней) определяется гиперэхогенное образование с чёткими границами размерами … × … мм, исходящее предположительно из … стенки матки, с единичным подходящим сосудом без ветвления».

### Хронический эндометрит

«Гипоэхогенный, без фазовой трансформации, тонкий, без срединной линии, без чётких границ с миометрием и без кровотока».

### Аденокарцинома

«Эндометрий утолщен, неоднородной эхоструктуры повышенной эхогенности (пониженной), без чёткой границы с миометрием и срединной линии, с выраженным хаотичным кровотоком (с множественными сосудами с разветвлением на концах)».

# Шаг 6. Полость матки

*Источник: страница 9.*

### Синехии полости матки — лучше видны во 2 фазе цикла

«Определяются линейные гиперэхогенные включения, пересекающие полость матки от передней к задней стенке, в верхних отделах справа / слева и др.».

### Серозометра

«Полость матки шириной до 3 мм, заполнена анэхогенным содержимым».

### Беременность раннего срока

«В полости матки определяется анэхогенное образование средним диаметром 3 мм (и более) с гиперэхогенным контуром — плодное яйцо».

### ВМС

#### Норма

«В полости матки определяется ВМС, расположена правильно, расстояние до дна … мм».

#### Экспульсия

«В полости матки определяется ВМС, нижний край расположен ниже внутреннего зева на … мм, не доходит до дна … мм».

### Гематометра после родов

«Шириной до 10–20 мм (и более, зависит от дня после родов), заполнена гипоэхогенным содержимым с неоднородными гиперэхогенными включениями (жидкая кровь со сгустками) без кровотока».

### Остатки после родов

«Шириной до … мм, в области дна определяется гиперэхогенное образование округлой формы размерами … × … мм с выраженным кровотоком (с единичным сосудом, исходящим из передней / задней стенки)».

# Шаг 7. Яичники

*Источник: страницы 10–11.*

**Каждый яичник описывается отдельно. В случае выявления образования производится расчёт O-RADS и / или по IOTA ADNEX MODEL.**

### Подвижность

- Подвижный.
- Фиксирован за маткой / у дна / у ребра матки.

### Фолликулы

- «Содержит … фолликулов диаметром … мм, … фолликулов диаметром … мм и доминантный фолликул диаметром … мм (средний размер)».
- Фолликулярный аппарат не выражен.

### Строма

- Обычной эхогенности.
- Гиперэхогенная в избыточном объёме.
- Преобладает.

### УЗ-признаки ПКЯ

- Более 20 фолликулов диаметром 2–9 мм, расположенных преимущественно по периферии.
- Объём более 10 см³.

### Образование

- «Определяется образование».
- В источнике указана отсылка: «см. подробно в методичке по яичникам». Сама методичка в этот PDF не входит.

### Простая киста

«Анэхогенное образование с гладкой тонкой / толстой капсулой без кровотока размерами … × … мм».

### Эндометриоидная киста

«Гипоэхогенное образование со взвешенным содержимым по типу “матовое стекло”, плотной капсулой, без кровотока (минимальным кровотоком), размерами … × … мм».

### Дермоидная киста — вариант описания

«Гиперэхогенное образование неоднородной структуры размерами … × … мм, дающее акустическую тень».

### Паровариальная киста

«Рядом с яичником определяется округлое анэхогенное образование с гладкими плотными стенками размерами … × … мм».

### Гидросальпинкс

«Между яичником и маткой определяется гипоэхогенное образование вытянутой формы размерами … × … мм с неполными поперечными перегородками».

### Тубовариальное образование

«Рядом с яичником определяется гипоэхогенное образование с неполными поперечными перегородками, тесно связанное и неотделяемое от яичника, общим размером … × … мм».

### Дополнительный вариант

- Не определяется.

# Шаг 9. Признаки глубокого инфильтративного эндометриоза

*Источник: страница 13.*

### Инфильтрат

«Определяется гипоэхогенное образование неправильной вытянутой формы без чётких границ и кровотока, размерами … × … мм».

### Локализация

- Между маткой и яичником.
- Ретроцервикально.
- В заднем своде влагалища.
- Между задней стенкой матки и передней стенкой сигмовидной кишки.
- В проекции правой / левой крестцово-маточной связки.
- В переднем компартменте между маткой и задней стенкой мочевого пузыря и др.

### Облитерация

- «Определяется симптом “головного убора индейца”».
- Задний свод облитерирован.

# App Store · iOS — материалы SonoGyn Pro

Соответствие [Guideline 2.3](https://developer.apple.com/app-store/review/guidelines/) и гайду Apple по creative assets (2026).

## Что загрузить в App Store Connect (минимум для пилота)

| Актив | Размер (iPhone 6.7") | Кол-во |
|-------|----------------------|--------|
| Скриншоты | **1290 × 2796 px** (portrait) | 5–10 |
| App Preview (опционально) | 886 × 1920 или 1080 × 1920, до 30 с | 0–3 |
| Иконка | уже в билде (`assets/icon.png`) | 1 |

Достаточно **одного набора 6.7"** — Apple масштабирует для других iPhone. Проверка: **Product Page Preview** в Connect.

## Раскадровка (порядок = история для врача)

1. **Калькуляторы** — главный таб, сетка инструментов (O-RADS, IOTA, акушерство).
2. **O-RADS Pro** — форма признаков, категория (без персональных данных пациента на скрине).
3. **IOTA / придатки** — чипы признаков, результат.
4. **BI-RADS / молочная железа** или TI-RADS — второй орган (показать ширину платформы).
5. **Evidence / справочник** — поиск по гайдлайнам (учебный контент).
6. **Вход** — email и пароль (пилот, без регистрации в app).

На каждом кадре — **короткая фраза** (см. `store-assets/app-store-copy-ru.json`), не дублирующая мелкий UI-текст.

## Правила Apple (кратко для медицины)

- Показывать **реальный UI** приложения, без «фейковых» диагнозов и без данных пациентов.
- Формулировки: **«справочный / ассистивный инструмент»**, **«интерпретацию выполняет специалист»** — не «диагноз», не «замена врача».
- Не указывать **цены**, URL сайта на скриншотах, награды, «лучший ИИ», логотипы Google Play.
- Контент **4+**: без шок-кадров, крови, откровенных изображений.
- Текст на скринах **локализуйте** (RU для РФ; при EN — отдельный набор).

## Сборка скриншотов (2 способа)

### A. Симулятор + рамки (рекомендуется)

```bash
cd apps/mobile
# Запустите приложение на iPhone 16 Pro Max (или 15 Pro Max) в Simulator
bash scripts/capture-ios-screenshots.sh
```

PNG появятся в `store-assets/captures/raw/`.

### B. HTML-шаблон с подписями

1. Откройте `store-assets/generate-frames.html` в Chrome.
2. Вставьте свои PNG в слоты (drag или замените `src`).
3. Экспорт: DevTools → скрин каждого `.frame` **1290×2796** или `bash scripts/export-app-store-frames.sh` (macOS `screencapture` + инструкция внутри).

# SonoGyn Pro — бета-тест O-RADS «Из описания»

> **Preview-деплой только.** Не используйте production-домен `sonogyn-pro.ru` для этой беты — работайте по ссылке, которую прислал координатор.

## Для кого

10 бета-врачей, тестирование AI-разбора фрагментов протокола УЗИ придатков (O-RADS US v2022).

**Важно:** категория O-RADS считается калькулятором по гайдлайну ACR — это **CDS, не диагноз**. Всегда проверяйте признаки и финальную категорию вручную.

---

## 1. Вход

1. Откройте **preview-ссылку** из письма координатора.
2. Войдите как обычно: **email + код** (OTP).
3. Убедитесь, что видите личный кабинет / калькуляторы.

---

## 2. Открыть калькулятор O-RADS

1. Перейдите в раздел **Калькуляторы** → **O-RADS**  
   (прямой путь: `/calculators/o-rads`)
2. Вверху переключатель режимов — выберите вкладку **«Из описания»**.

---

## 3. Разбор текста

1. Скопируйте **фрагмент протокола** (описание образования яичника) в текстовое поле.
2. При необходимости укажите **менопаузу** (пременопауза / постменопауза).
3. Нажмите **«Разобрать описание»**.
4. Проверьте блок **«Извлечённые признаки»** (размер, кровоток, перегородки, асцит и т.д.).
5. Посмотрите **черновик категории** (O-RADS N), если все шаги определены.

### Примеры для проверки (можно вставлять как есть)

```
Образование в правом яичнике 45x32x28 мм, солидный компонент, кровоток по ЦДК определяется, асцита нет
```

```
Киста левого яичника 60x45x40 мм, гладкие контуры, анэхогенная, без перегородок, ЦДК отрицательный
```

```
Образование правого яичника 38x28x22 мм, солидное, с неровными контурами, кровоток усилен, асцит +
```

```
Киста левого яичника 40x35x30 мм, с внутренними перегородками, кровоток по ЦДК отсутствует, асцита нет
```

---

## 4. Заполнение wizard

1. **«Заполнить (только high)»** — автоматически проставляет только уверенные шаги.
2. **«Подсказки в wizard»** — проставляет все подсказки; остальное допроходите вручную.
3. Переключитесь на вкладку **«Пошагово»** и **подтвердите** каждый шаг.
4. Сравните итоговую категорию wizard с тем, что вы бы поставили по протоколу.

---

## 5. Feedback (обязательно)

После разбора внизу блока:

1. **«Правильно ли AI определил категорию?»**
2. **Да** — если черновик совпал с вашим решением.
3. **Нет** — укажите **правильную категорию O-RADS (1–5)** и отправьте.

Это помогает улучшить парсер после 2 недель сбора данных.

---

## 6. Что фиксируется (для координатора)

При нажатии «Разобрать» (если вы авторизованы) в Supabase сохраняется:

- исходный текст;
- извлечённые признаки;
- черновая категория AI;
- ваш feedback и ручная категория.

Персональные данные пациенток **не вводите** в поле описания — только анонимизированные фрагменты протокола.

---

## 7. Если что-то не работает

| Симптом | Что сделать |
|--------|-------------|
| Не открывается preview | Напишите координатору, пришлите скрин |
| «Разобрать» без ошибки, но нет feedback | Выйдите и войдите снова (нужна сессия) |
| Категория «не все шаги определены» | Нормально — дойдите wizard вручную с подсказками |
| Нужна диктовка | На web доступна кнопка **«Диктовка»** (Chrome/Edge) |
